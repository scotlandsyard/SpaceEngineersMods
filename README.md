# SpaceEngineersMods

Space Engineers workshop mods. Each mod lives in its own folder with a README that explains what it does, how to test it and how it is published.

| Mod | What it does |
|---|---|
| [Tiered Gas Bottles](TieredGasBottles/) | Three bigger oxygen bottles and three bigger hydrogen bottles, tiered like the vanilla hand tools |

Mods are installed through the Steam Workshop: a server admin adds the mod to the world and every player downloads it automatically.

The client-side plugins for the Pulsar plugin manager are in [SpaceEngineersPlugins](https://github.com/scotlandsyard/SpaceEngineersPlugins).

## Reporting bugs

Open an issue with the mod's name in the title (one issue per bug). Say what you did, what you expected and what happened instead, and attach the game log (`%AppData%\SpaceEngineers\SpaceEngineers_<date>.log`) if you can. For a server, the server's log for the same time helps too.
